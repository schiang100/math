Part 0 · 全域地圖

為什麼電機所考試都要考「工程數學」？

依據成大圖書館電機系碩士班考古題（75–115 學年度）與ColleGo! 電機工程學類課程地圖，工程數學不是考背公式，而是把「電路、訊號、控制系統」翻譯成數學後，挑選最省力工具的總稱。

1. 先寫出物理現象

時域模型（ODE）

電容充放電、馬達轉速、彈簧避震器，寫成物理定律都是「變化率」，也就是常微分方程。

核心問題：系統下一秒會怎麼動？
2. 換個視角降維打擊

轉換域（Laplace / Fourier）

直接算微積分太慢？轉到 s 域 變四則運算，或轉到 頻率域 看清訊號成分。

核心問題：怎麼算最快、濾掉雜訊？
3. 處理多變數與棘手積分

矩陣與複數平面

多顆感測器耦合用「線性代數對角化」拆開；實數軸算不出來的積分，繞進「複數平面」用留數定理秒殺。

核心問題：多維系統穩不穩定？
Part 1 · 常微分方程（ODE）

ODE：用現在的狀態，預測下一秒的變化

把電容充電（一階）或車子避震器彈跳（二階）寫成數學式，就是 a y'' + b y' + c y = g(t)。總解永遠由「系統天性 y_h」加上「外力強迫 y_p」組成（來源：Paul's Notes）。

二階系統的三種「天性」（特徵根決定）

解特徵方程式 a r² + b r + c = 0：

1. 兩相異實根 → 過阻尼（Overdamped）
像在濃糖漿裡關門：慢慢平滑歸位，完全不晃動。
2. 重根 → 臨界阻尼（Critically Damped）
最快回到平衡且不震盪；解要補乘 t 維持線性獨立。
3. 共軛複根 → 欠阻尼（Underdamped）
像撥動吉他弦：先來回震盪（sin/cos），再隨指數衰減。

新手三步解題 SOP

  1. 先判斷階數：一階先試分離變數或積分因子；二階常係數寫出特徵方程式。
  2. 拆成齊性解 + 特解：用待定係數法或參數變換法求外力響應 y_p。
  3. 代入初始條件：用 y(0), y'(0) 算出未定常數。
考場避雷：如果猜測的特解 y_p 跟齊性解重複，一定要乘上 t 修正，否則代回去會全部消掉變成 0！
Part 2 · 拉普拉斯轉換與摺積

Laplace 轉換：把微積分變四則運算的翻譯機

把時域微分方程取 Laplace 轉換後，微分變成乘上 s、初始條件自動帶入，解完代數再查表逆轉換（或用摺積定理 L⁻¹{F(s)G(s)} = f * g）回到時域（來源：Paul's Notes IVP）。

三步解決初值問題（IVP）
Step 1 轉換：L{y'} = sY(s) - y(0)
Step 2 代數解出 Y(s) 並部分分式展開
Step 3 查表逆轉換或使用摺積積分
互動調整阻尼比 ζ（觀察 s 域極點如何決定波形） 0.30
欠阻尼（共軛複極點）：明顯震盪後收斂
二階系統標準轉移函數 G(s) = ωn² / (s² + 2ζωn s + ωn²) 步階響應 目標值 = 1.0
Part 3 · 傅立葉級數與轉換

傅立葉分析：任何波形都能用正弦波拼出來

就像音樂等化器（EQ）把聲音拆成低音與高音，傅立葉級數把週期訊號拆成不同頻率正弦波的疊加，讓線性系統可用「疊加原理」逐頻求解（來源：MIT OCW 18.03SC）。

奇函數方波合成：f(t) = (4/π) Σ sin((2k-1)t) / (2k-1) 虛線 = 理想方波
拖動疊加諧波數量（N） N = 3 個奇次諧波
諧波越多越接近方波，但邊緣會保留約 9% 的「吉布斯現象」凸起。
考場省時捷徑：奇偶對稱性
• 偶函數（左右對稱）→ 只算 a_n（cos），b_n = 0
• 奇函數（原點對稱）→ 只算 b_n（sin），a_0 = a_n = 0
延伸到非週期訊號：當週期 T → ∞，離散的諧波係數就連成連續頻譜，成為通訊與訊號處理核心——傅立葉轉換。
Part 4 · 線性代數核心

特徵值與 SVD：找出多維系統「不偏轉的主軸」

當系統有好幾個互相牽連的變數時，矩陣變換會讓向量又轉又拉；唯有沿著特徵向量方向，矩陣只做純伸縮 Ax = λx（來源：MIT OCW 18.06SC）。

1. 矩陣對角化
A = S Λ S⁻¹

把糾纏的座標系換到特徵向量上，讓矩陣高次方 Aᵏ = S Λᵏ S⁻¹ 與矩陣指數 e^(At) 瞬間變成對角線直接算。

條件：需有 n 個線性獨立特徵向量
2. 微分方程組解耦
u'(t) = A u(t)

高階 ODE 改寫成狀態矩陣後，解即為 u(t) = e^(At) u(0)。特徵值實部全小於 0，代表系統穩定收斂。

不可對角化時改用 Jordan Form
3. 奇異值分解（SVD）
A = U Σ Vᵀ

不限方陣！任意 m×n 矩陣都能拆成「旋轉 → 伸縮 → 旋轉」，奇異值由 AᵀA 的特徵值開根號取得（MIT SVD）。

應用：最小平方法、影像壓縮、降維
Part 5 · 複變函數與留數定理

留數定理：圍住「奇點」，實數難題瞬間有解

在複數平面畫一條封閉圍欄 C：如果裡面處處光滑（解析），積分必為 0；只要抓出圍欄裡的「奇點（分母為 0）」，把留數相加乘上 2πi 就是答案（來源：MIT OCW 18.04）。

∮ f(z) dz = 2πi · [ Res(z₁) + Res(z₂) ]
Step 1 · 抓出圈內奇點
解分母為 0 的所有極點，只保留落在封閉路徑 C 內部的點（例如算實軸瑕積分時只取上半平面 Im(z) > 0）。
Step 2 · 計算留數（Residue）
一階極點直接蓋住消掉：Res(f, z₀) = lim (z - z₀) f(z)；m 階極點則微分 (m-1) 次再除以 (m-1)!。
Step 3 · 乘上 2πi 收尾
把所有圈內留數相加乘上 2πi，即可解出原本在實數軸上無從下手的定積分。
